# R58-T013 evidence

Run from the repository root:

```bash
python3 work/R58-T013/check.py
```

The checker copies the exercise, including dotfiles, into two isolated temporary directories. It runs all enabled tests against the maintained reference in the first copy. In the second copy only, it changes the encoder's seven-bit shift to a six-bit shift and runs `testSmallestDoubleByte`. The expected result is that the original passes and the mutant is rejected by that exact test.

The checker records the test counts, failing test name, command, tool versions and learner-file hash result in `latest-result.json`. It does not modify the learner starter file or maintained reference in the working tree.

Execution evidence is generated by running the command above; no local execution result is claimed in this commit.
